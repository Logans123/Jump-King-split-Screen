# Jump King — Split Screen

A split-screen Jump King clone built with p5.js and simple neuroevolution/agents.

## Quick start

Prerequisites: Node.js (optional, for the local static server).

Install dependencies and start a local server:

```
npm install
npm start

# Open: http://localhost:5000
```

Alternatively open `index.html` directly in a browser for quick testing.

## Project structure

- `index.html` — entry point
- `sketch.js`, `sketch-LAPTOP-4GTCNHGO.js` — p5 sketches
- `Player.js`, `Brain.js`, `Population.js` — game/AI logic
- `attached_assets/`, `images/`, `sounds/` — assets
